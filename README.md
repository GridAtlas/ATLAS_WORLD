# アトラス大全 ― ATLAS WORLD

SF・映画・文学の名作を「型の分類」と「年表」の二層で読み解く系譜集、全6冊・全221作の玄関。

公開ページ： <https://gridatlas.github.io/ATLAS_WORLD/>

## 収録アトラス

| 冊 | 内容 | 収録 |
|---|---|---|
| [仮想現実アトラス](virtual-reality/) | この世界は本物か？ シミュレーションと仮想現実の系譜 | 全54作 |
| [時空間アトラス](spacetime/) | 時間を移動し、繰り返し、書き換える物語の系譜 | 全55作 |
| [管理社会アトラス](management-society/) | 神の監視から哲人王、工場の管理、スコア社会まで――人間を管理する夢の系譜 | 全26作 |
| [ポストアポカリプスアトラス](post-apocalypse/) | 世界がどう終わり、何が残ったかで読む系譜 | 全27作 |
| [終焉アトラス](end-of-the-world/) | 世界の終わる直前、カウントダウンを生きる物語の系譜 | 全19作 |
| [人工知能アトラス](ai/) | 作られた知性に心はあるか。「何をもって意識があると判定するか」を軸に読む系譜（下書き） | 全40作 |

シリーズの構図は、世界の危機の時間軸をたどる3冊（管理社会・終焉・ポストアポカリプス）と、全時代に差し込む根源的な問いの3冊（仮想現実・時空間・人工知能）である。

トップページ（大全）は [index.html](index.html)。

関連：年表として作品と思想を同じ時間軸で眺める先の試みに、[Timeline Atlas](https://gridatlas.github.io/TIMELINE_ATLAS/) がある。
